#   id   module  SpawnInfo    factory      table        RTTI            width
#   348  ov002   0x021085d4   0x020b0980   0x021085f8   10daChRoom_c    31
#   314  ov039   0x02111834   0x0211137c   0x02111858   11daObjKumo_c   31

# Both derivations are BY ADDRESS and both name shifts are spelled out in the
# header of hal/actor_classes_ov_link100.cpp, which is the fill. The short

# one same-module data load, and that address's -4 word is the class's Itanium
# typeinfo pointer. dsd's names are one class late for 348 and doubled for 314;
# neither is used to decide anything.
