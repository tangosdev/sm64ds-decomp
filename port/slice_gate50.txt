#
# Six paintings on level 2's object table, all printed as skipped (- 307 x6)
# until this gate. The class is an ordinary 31-slot Actor subclass whose seven
# own methods are matched src (InitResources 0x02126ca0, CleanupResources
# -- of which InitResources/Behavior/Render are HELD OUT since 2026-08-08:
# their per-mode PMF dispatch is the incomplete-class case MSVC widens, so
# they are host copies in port/unmatched/Painting_Dispatch.cpp (the door's
# treatment). CleanupResources and OnPendingDestroy still compile from src.
# 0x02126bfc, Behavior 0x02126c60, Render 0x02126c20, OnPendingDestroy
# 0x02126c1c, D1 0x02125404, D0 0x02125428) plus the closure they reach.
#
# THE PAINTING DISPATCHES A POINTER-TO-MEMBER. InitResources reads
# data_ov080_02128628[mi] (mi = (flags>>0xd)&3) as a {function, delta} record,
# calls it as (self->*pmf)(), and stores &data_ov080_02128628[mi] at self+0x1a4;
# Behavior reads +0x8 off that pointer and Render +0x10, so a painting at index
# mi runs the run {init=[mi], behavior=[mi+1], render=[mi+2]}. The twelve records
# are built by __sinit_ov080_02127b2c out of source statics whose function words
# carry DS code addresses, so hal/actor_overlays.cpp seats host bodies over the
# statics before the copy -- the butterfly/rabbit treatment, all twelve deltas
# zero (a complete class, the smallest mwcc PMF), so no host copy of the three
# dispatchers is needed.
#
# ONE STATE FUNCTION IS UNMATCHED. Record index 5's function is
# func_ov080_021261f4 (0x2f8 bytes, no src, not in nearmiss) -- the render half
# a painting with mi=3 would run. The seat installs a loud trap over it, the
# rabbit's 0x0212b8dc treatment: measured, no level-2 painting reaches it (all
# six run 300 frames fault-free), and a painting that did would abort by name
# rather than jump into the overlay image.
