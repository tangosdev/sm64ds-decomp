# Gate 14: the real level boot -- Stage::LoadClsnAndObjects over the castle
# grounds' own LVL_Overlay (ov009, mounted whole; see tools/ovdata.py).
#
# Everything here is MATCHED in src. The boot is one function plus the
# fifteen sub-loaders it dispatches through data_ov002_0210cbb8 and the
# pointer-store setters those write into. What it replaces in the harness:
# a hand-constructed MeshCollider over handle 1941, an invented spawn point,
# a zeroed CLPS block, and two 0xff pins that stood in for a path table
# nobody had loaded.
#
# The seam is hal/level_boot.cpp: LoadFile(handle) over SharedFilePtr, the
# 32-entry host copy of the loader dispatch table (the ROM's is 15 entries
# and the `kind & 0x1f` index is unguarded), and storage for the globals the
# setters fill.
