# Gate 149: HAUNTED_CHAIR (326), Big Boo's Haunt's rocking-chair actor, level
# 12's own overlay ov020. ov020 is mounted whole in PORT_LEVEL_OVERLAYS and per
# symbol in PORT_ACTOR_OVERLAYS so the class reaches its SpawnInfo record and its
# model SharedFilePtr static by name (the gate-59 shape). The vtable fill, method
# faces and the two data-linkage aliases are in hal/actor_classes_bbh.cpp.
#
# WHY ONLY THIS ONE OF THE FOUR ov020 FURNITURE CLASSES. Big Boo's Haunt's
# object table also names BOOKEND (327) and BOOK_SHOT_SPAWNER (328); both spawn
# BOOK_SHOT (325) at runtime. BookShot's state-9 behaviour (func_ov020_0211174c,
# the book flying back to its shelf) calls func_ov063_0211cae8 on the Bookshelf
# actor it homes to -- an ov063 function that is NOT decompiled (no src TU) and
# ov063 is not mounted. Hosting BookShot with that call stubbed would be a
# non-ROM-faithful boot, so the three book classes stay skipped by name at the
# gate and are documented blockers. HauntedChair reaches nothing outside ov020:
# its whole helper closure (_ZN12HauntedChair6State3Ev/02112b00/02112e94/021130c8/
# 02113148/021131f8/02113240) is matched src in ov020, and it loads only its own
# model. So it hosts clean on its own.
