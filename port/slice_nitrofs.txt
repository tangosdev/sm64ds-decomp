# Run link100, lane NITROFS: the ROM's own NitroFS init, and the cartridge
# lock arm of the registration group behind it.
#
# WHAT UNBLOCKED IT. src/func_0205d96c.c reads four cartridge-header words out
# of the mirror at 0x027FFE40 / 0x027FFE48 and returns early on 0 or -1.
# hal/fs_names.cpp said those pages were unmapped; they were not, and never
# had been (ntr/include/ntr/mmio.h:36, ntr/io.cpp kRegions with fatal = true,
# hal/os_lockid.cpp writing 0x027fffb0 on the same page). The mirror was
# mapped, zeroed, and never written. hal/nitrofs_boot.cpp writes it, from the
# four words tools/asset_catalog.py already takes out of the cartridge header,
# and the ROM's own body runs.
#
# THIS SLICE GOES TO walk_window AND walk_window_hires ONLY. The archive
# command proc reaches hal/boot_hw.cpp's four transcribed OS primitives
# (func_02057198, func_0205a74c, func_02059d8c, IRQ::DisableAll /
# IRQ::RestoreAll) and that file rides SLICE214_SOURCES, which smoke_player
# does not carry. smoke_player keeps the face, alone, in hal/nitrofs_face.cpp.
#
# THREE PER-SOURCE RENAMES in port/CMakeLists.txt carry the three edges that
# are not ROM code yet; hal/nitrofs_boot.cpp holds the three faces and says
# what each one names. The matched TUs behind them stay unenrolled and
# unclaimed, so none of them becomes a new SHADOW row.
