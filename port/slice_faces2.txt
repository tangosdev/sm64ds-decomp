# Every row here is a translation unit that exists in src/ on this branch, owns
# at least one symbol walk_window.exe still reported unresolved after lane
# FACES1's 1464 generated faces (1290 externals, out/FACES1/residue.txt), and is
# compiled by NOTHING: not on a slice list, not in a CMake block, not in a
# hostgen generation list, and not an object on walk_window's, walk_window_hires'
# or smoke_player's own link line. It is lane SLICE1's batch 1 continued: main's
# 2026-09 consolidation folded one-function TUs into class TUs and the port never
# took the new files.
#
# HOW THE SET WAS DERIVED, and none of it is a filename scan.
#
# 1. The universe is walk_window.exe's OWN unresolved block (build_f2.log, 1290
#    externals), every row of it, decorated and flat.
# 2. Each row is turned into the source-level token that would define it: a flat
#    ROM name is itself, a decorated member is Cls::meth read back out of the
#    mangle (MSVC writes a qualified name innermost first, so the components are
#    reversed). 783 of the 1290 have exactly ONE uncompiled src TU carrying that
#    token.
# 3. COLLISION PREDICTION IS PER SYMBOL, through the delinks. config/**/delinks.txt
#    gives each src file its ROM address ranges, that module's symbols.txt names
#    every function body inside them, and the candidate is held unless NOTHING
#    already on the link line defines any of those bodies. 29 candidate TUs
#    collide that way and are NOT here; they answer 464 of the 783 rows between
#    them and each needs a host copy retired or a hostgen substitution first, so
#    they are listed with their colliding object in
#    runs/link100/out/FACES2/slice_held.txt. The biggest is src/actors/Player.cpp
#    at 149 rows, which is the SYNC5 quarantine (MSVC refuses main's shape for
#    it) and a decomp-side item, not a port one.
# 4. A candidate already carried by another slice list, under any target, is held
#    too: a second row for one path is a second object and an LNK2005.
#
# 246 TUs, answering 303 of the 1290 unresolved externals. A row that turns out to
# duplicate a body already in the build, or that MSVC refuses, is COMMENTED OUT
# IN PLACE with its reason rather than deleted, so the next lane can see what was
# tried.
