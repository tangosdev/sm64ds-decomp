# ==== THE TABLE IS THREE ENTRIES, NOT SIX CELLS ============================
# func_ov018_021123d0(self, i) is `add r1, r2, r1, lsl #4` -- a SIXTEEN-byte
# stride over data_ov018_02113c4c, whose six 8-byte records
# __sinit_ov018_02112c80 copies at offsets 0, 8, 0x10, 0x18, 0x20, 0x28. So
# the table is three 16-byte entries of two pointer-to-member records:
#
#   state 0   enter func_ov018_021122ec (sets +0x37c = 0)   LINKED at gate 191
#             tick  func_ov018_02112234
#   state 1   enter func_ov018_021121dc (sets +0x37c = 1)
#             tick  func_ov018_02111fac
#   state 2   enter func_ov018_02111f1c (sets +0x37c = 2)
#             tick  func_ov018_02111e28
#
# THE UNIVERSE IS CLOSED BY THE ROM. All eight arm_call relocations into
# func_ov018_021123d0 set r1 in the instruction before the branch:
#   0x0211258c=0 (InitResources)  0x02112170=0  0x02112010=0 (both 02111fac)
#   0x02111f44=0 (02111f1c)       0x02111f04=0 (02111e28)
#   0x021119b4=1  0x02111a38=1 (both 02111968)  0x02111bdc=2 (02111b3c)
# i is never 3 or more, so nothing indexes past the 48-byte table and there
# is no fourth state to find.
#
# ==== WHAT REACHES WHAT (the ROM's own graph, not a keep-alive) ============
# MotherPenguin::Behavior 0x02112480 -> bl 0x0211235c (module overlay(18),
