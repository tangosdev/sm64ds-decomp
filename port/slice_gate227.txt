# was therefore refused by port/tools/inferred_stub_guard.py. Lane STUBADJ ran
# the whole unlinked marker set -- 112 files -- through tools/match.py at each
# symbol's exact config address and size under the pinned mwccarm 2004/b56 with
# --strict-relocs, and 112 of 112 reproduce the ROM. Its 71 new REAL_DECOMP
# rows are in port/tools/inferred_stub_adjudicated.txt; the guard reads them
# and admits exactly the symbols that carry a ruling.
#
# WHAT THIS LANE CHECKED BEFORE SEATING, per body, because a ruling in a file is
# not the same as a word in the ROM:
#
#   1. the TABLE WORD. Read config/<module>/relocs.txt at vtable + 4*slot and
#      confirmed the destination is this body's address. Never read off a class
#      name: the tree's recovered names are shifted (Trap=Hikari,
#      SkiLift=daPgMthr_c), the addresses are not.
#   2. the ENTRY. config/<module>/symbols.txt carries a
#      kind:function(arm,size=..) record AT that exact address, and the
#      disassembly at it is an ARM prologue. None is an interior address of a
#      tail-shared body -- a fabricated .c at an interior address has been
#      seated by mistake on this port before.
#   3. the CALL SHAPE. hal/actor_classes.cpp states the port's contract:
#      slots 19 and 21..28 are dispatched by a __thiscall caller that PUSHES one
#      argument, so their faces are THREE-parameter __fastcall and pop it;
#      slots 20, 29, 31 and the lifecycle slots 0/3/6/9/12/16/17 push nothing
#      and take the two-parameter shape. Every face below is written at the
#      arity the ROM body actually takes, read out of the disassembly, and the
#      trap it replaces is checked against the same contract.
#   4. the BINDINGS. Where a body spells a global with a shared-header
#      placeholder (VT/VT0/VT1/HEAP/G0), the -D row in port/CMakeLists.txt is
#      read out of THAT BODY'S OWN literal pool in config/<module>/relocs.txt,
#      never out of the recovered name.
#
