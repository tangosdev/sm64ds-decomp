# Each file below is a per-function src D0 TU that gained the Model family's
# `#ifdef _MSC_VER` arm (src/_ZN5ModelD0Ev.cpp is the shape), with the
# campaign's one deliberate difference: the destructor call is QUALIFIED
# (thiz->Cls::~Cls()), because this tree's headers declare these destructors

# while main's headers declare them `virtual`, and a plain `thiz->~Cls()`
# would be a virtual call through the port's ROM-shaped table there. The
# qualified call is direct in both header worlds; the object is
# byte-identical to the file's own previous destructor definition either way
# (mwccarm never defines _MSC_VER).
#
# Per-row provenance (ROM address, deallocation, heap word, proof level) is
# the campaign recipe's plan.tsv, banked under this lane's own out/ directory;
# the retired port/faces_sync.txt row for each stem carries the same
# information inline as a RETIRED comment.
