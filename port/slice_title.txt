# a link root. The arm9 ACTOR_SPAWN_TABLE (0x02090864) relocates slot 2 to

# dScTitle_c_classInit, the same three statements every other scene row makes.
# g_profile_TITLE's own +0 word relocates to 0x020adc10, which IS the factory
# (config/arm9/overlays/ov003/relocs.txt:586), and its +4 halfword reads 2 back
# -- the registry's own cross-check. The class vtable is the host array the
# fill writes the ROM's own slot contents into, which is what names the six
# bodies; everything else here is reached from one of those entry points.
# Nothing is /include:'d, no alias points at any of it, and no call is made
# from a place the ROM does not call.
#
