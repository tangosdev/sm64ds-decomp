# port/slice_seats2.txt -- lane SEATS2, run link100 wave 9b.
#
# SEATS, BOTTOM-UP. Every row here is a translation unit that exists in src/,
# owns flat ROM names walk_window reports unresolved, and is compiled by
# nothing: not on a slice list, not in a CMake block, not in a hostgen
# generation list, and not an object on walk_window's own link line.
#
# WHAT WAS MEASURED BEFORE A ROW WAS WRITTEN. Each candidate was compiled
# STANDALONE with the build's own flags, and its object's symbol table was read
# against two lists: walk_window's 579 unresolved names at 8dc06444f, and the
# 48406 defined externals of its own 8663 link inputs. A row is here only when
# that object CLOSES rows, DUPLICATES nothing, and REFERENCES nothing the link
# cannot already answer.
#
# The duplicate half of that test reads the COMDAT SELECTION out of each
# section symbol's auxiliary record, not just the COMDAT flag. /O2 implies /Gy,
# so every function MSVC emits here is in its own COMDAT and a census that
# stops at the flag predicts no duplicates at all; an out-of-line body's
# selection is 1, "pick no duplicates", which is the LNK2005. Four of the class
# TUs below duplicated one to six names on that test, and every one is
# parked in the hostgen copy rather than fought over -- see the SEAT_PARK block
# in port/tools/hostgen.py for what a park is and why it is not a retirement.
#
# FIVE OF THE SIX ROWS GO THROUGH hostgen (PORT_HOSTGEN_TU at the top of
# port/CMakeLists.txt), so the rows below are rewritten to
# build/port/host-src/<path> as they are read. The raw text is never compiled.
# hostgen does four things to them: it parks the bodies the link already
# defines, it gives daPkn_c's and daGmch_c's vtable externs C linkage, it drops
# the Itanium +8 address-point bias from every vptr store, and it applies the
# standard MMIO and attribute rewrites.
