# Gate 18: the castle grounds' RABBITS, and the Lakitu with the camera.
#
# ov085 is the first overlay the port mounts that is neither the engine
# overlay (ov002) nor the level's own (ov009). It is an ACTOR overlay: six
# classes that several levels pull in, of which the castle grounds names two.
#
#   RABBIT      (187) x12   the twelve glowing rabbits, an AI actor that
#                           flees the nearest player and is caught by touch
#   LAKITU_BRO  (235) x1    the cameraman, who reads the real Camera's own
#                           state to place himself
#
# THE CONFIG'S NAMES ARE NOT SHIFTED HERE, and that is a finding rather than
# an assumption: ov009 taught the port to check. Every one of ov085's six
# factories installs a vtable whose slot 0 is its OWN class's InitResources
# and whose slot 16 is its OWN D1 --
#
#   Toad_Spawn          -> _ZTV11daKinopio_c      slot0 Toad::InitResources
#   PrincessPeach_Spawn -> _ZTV9daPeach_c         slot0 PrincessPeach::...
#   Rabbit_Spawn        -> _ZTV7daMip_c           slot0 Rabbit::InitResources
#   RabbitKey_Spawn     -> _ZTV15daObj_Mip_Key_c  slot0 RabbitKey::...
#   LakituBro_Spawn     -> _ZTV11daC_Jugem_c      slot0 LakituBro::...
#   WallSign_Spawn      -> _ZTV13daObjKanban_c    slot0 WallSign::...
#
# -- so the block before each factory really is that factory's class, and the
# ROM's own RTTI names agree (daMip_c is the rabbit, daC_Jugem_c the Lakitu).
