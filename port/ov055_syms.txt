# ==== THE TWO-HALF POINTER-TO-MEMBER CELL AND ITS T3 PIN ==================
#
# The smallest instance of the machine ov030, ov032 and ov034 all carry: ONE
# sixteen-byte cell, two 8-byte mwcc {function, delta} pairs.
#   data_ov055_02111a94 = {0x021112bc func_ov055_021112bc, 0}   the ENTER half
#   data_ov055_02111a9c = {0x02111288 func_ov055_02111288,  0}   the TICK half

# the cell through func_ov055_021112c4, which stores it at this+0x1d8 and
# tail-calls the ENTER half; MirrorLuigi::Behavior reads the cell back from
# +0x1d8 and dispatches the TICK half at cell+8 every frame. What the tick does
# is the class's whole point: it mirrors the player's position and Y angle
# (x = -x, angle = -angle), which is why a MIRROR Luigi.
# Both dispatch sites are host copies; hal/actor_classes_ov055.cpp VERIFIES all
# four ROM words in the mounted cell before rewriting the two function words
# with host addresses.
#
#   data_ov055_02111b70:0x10  THE PIN. Natural 0x4 -- dsd named 0x02111b74 four
#     bytes in, so the landing mounts ONE WORD OF FOUR and the sinit's last

#     host linker put next. It is the same shape as the ov002 incident T3 was
#     written from (a 12-byte list node hosted as four), one size up.
#     0x02111b74 is marked `ambiguous`, is spelled by no src TU, and is
#     deliberately not in the list.

# ==== ONE MORE T3 PIN =====================================================

#     exactly the vtable's own offset-to-top word, which pins it independently.
