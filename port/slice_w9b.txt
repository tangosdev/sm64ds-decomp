# stores, THREE ids share one vtable and THREE more share another:

#     id 200 g_profile_KURIBO               -> 0x02130948   REGISTERED
#     id 201 g_profile_KURIBO_S          -> 0x02130948
#     id 202 g_profile_KURIBO_L          -> 0x02130948   this slice
#     id 250 g_profile_PAKUN         -> 0x02130c28   REGISTERED

# 0x02130948 is already the host array _ZTV6Goomba[31] that

# 0x02130b28 is already _ZTV19FirePiranhaPlantBig[31] that
# hal/actor_classes_l7.cpp fills. Both fills are reached by an id that is

# All three SpawnInfo records are ALREADY MOUNTED in port/ov084_syms.txt,
