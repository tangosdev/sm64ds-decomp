# Gate 192: ov081, a 100% matched ACTOR overlay (113/113 chaos-db) carrying
# five classes -- SPINDRIFT (312), MR_BLIZZARD (223), SNOWBALL (unhosted),
# MONEYBAG (unhosted), ICE_BLOCK (18). Fresh per-symbol mount, the
# ov079/ov080 convention: WHOLE data span (every data + bss symbol) MINUS
# the three classes this gate hosts' own vtables (host arrays
# hal/actor_classes_ov081.cpp fills) MINUS dsd's five .p__sinit_* pointer
# entries (not C identifiers; the port calls the three sinits it runs by
# name directly). ovdata.py's --pack mode pads the resulting address gaps
# automatically, reproducing the ROM's own relative offsets.
#
# THE THREE VTABLES LEFT OUT: _ZTV9Spindrift (0x0212887c, 32 words, the full
# Enemy shape with own Kill at 31), _ZTV10MrBlizzard (0x021289f0, 32 words,
# own OnPendingDestroy at 12 -- NOT the shared default), _ZTV8IceBlock ==
# _ZTV15daObjIceBlock_c (0x02128cc4, 32 words, the full Platform+Kill shape,
# own Kill at 31). Every slot read with relocations applied (not just the
# scope report's named subset):
#
#   SPINDRIFT (daHuwa_c):
#     0 Init 0x02123ed0, 3 Cleanup 0x02123bec, 6 Behavior 0x02123c6c,
#     9 Render 0x02123c1c, 12 OnPendingDestroy SHARED, 16 D1 0x02123740,
#     17 D0 0x02123788, 18 OnYoshiTryEat 0x02124038, 19 OnTurnIntoEgg
#     0x02123fd8, 29 OnAimedAtWithEgg 0x021237e4, 31 Kill 0x02124e64 (own).
#
#   MR_BLIZZARD (daYuki_c): a REAL 10-cell (5 states x enter/tick) PMF
#     dispatch, sinit-copied as DS code addresses from data_ov081_0212893x
#     range statics into data_ov081_02128e14..ea4 (10 x 8 bytes). Own slots:
#     0 Init 0x02125ba0, 3 Cleanup 0x021257b0, 6 Behavior 0x0212588c,
#     9 Render 0x02125820, 12 OnPendingDestroy 0x0212581c (OWN, not shared),
#     16 D1 0x02124090, 17 D0 0x021240d8, 29 OnAimedAtWithEgg 0x02125eb8,
#     31 Kill 0x021261b8.
#
#   ICE_BLOCK (daObjIceBlock_c, a Platform): 0 Init 0x02127ff0, 3 Cleanup
#     0x02127d98, 6 Behavior 0x02127e1c, 9 Render 0x02127ddc, 12
#     OnPendingDestroy SHARED, 16 D1 0x02127b34, 17 D0 0x02127b80, 27
#     OnHitByMegaChar 0x02127ccc, 31 Kill 0x02127cf4 (own, per the report).
#     InitResources calls MovingMeshCollider::SetFile with a CLPS_Block read
#     from ov002 (data_ov002_0210d8d4, added to port/ov002_syms.txt).
#
# SNOWBALL and MONEYBAG stayed UNREGISTERED at gate 192, and their vtable
# words rode along as plain packed data because nothing installed them. LANE
# w3-b (run rel0215) REGISTERS BOTH, so both tables have to leave the mount:
# a registered class's factory stores the table into slot 0 of a live object,
# and the mounted bytes are the ROM's own words holding DS code addresses.
# _ZTV8Snowball (0x02128abc, 31 slots) and _ZTV8Moneybag (0x02128c04, 31
# slots) are now HOST ARRAYS hal/actor_classes_ov081.cpp declares and fills,
# the same rule this list already applies to the trio's three tables. Each
# vtable's own RTTI-alias spelling (_ZTV12daSnowball_c == _ZTV8Snowball,
# _ZTV8daGmch_c == _ZTV8Moneybag) shares the identical address, so dropping
# the one listed name drops BOTH spellings from the link -- which is what
# lets that file route the RTTI spelling with an /alternatename whose LHS is
# undefined everywhere, the IceBlock/daObj1UpLogo_c shape rather than the
# Spindrift/MrBlizzard one two lines up (those two keep the RTTI spelling
# MOUNTED, so their D0's first store lands on the ROM's raw words; inert
# because it is immediately followed by the teardown, but not a shape to
# copy).
#
# --pack pads the two resulting gaps (0x7c bytes each, the exact table
# widths) by itself. The two SpawnInfo records that PRECEDE the removed
# tables are pinned :0x24 -- their real ROM span, the delta to the table
# that used to follow them -- so the mount emits the same bytes it did
# before rather than letting the next-symbol floor stretch each record over
# the hole the removal left (trap T3, in the direction that oversizes).
#
# ovdata.py's --pack size floor is max(4, next-symbol-delta): two adjacent
# 2-byte fields (data_ov081_021289a4/a6, part of MrBlizzard's SpawnInfo
# record) need explicit :0x2 overrides or the floor makes the first one
# overlap the second.
#
