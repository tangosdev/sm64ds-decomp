# The ten readers of CUTSCENE_OBJECT's ten pointer-to-member state tables.
# port/hal/cutscene_states_link100.cpp hosted all ten as an address switch and
# now hosts none of them: it is the SEAT over the sixty-nine source records
# __sinit_ov002_02107370 copies into the tables, one __fastcall face per CELL.
#
# The per-row measurement (ROM read, emitted operand, arity, source pairs, the
# reference sweep) is in that file's header and in runs/link100/out/PMFB6/.
# Nothing here changes a ROM reference, a linker option or a call the ROM does
# not make: the ROM's own sinit fills the tables, the ROM's own readers index
# them, and the body each cell reaches is the decomp's matched TU.
#
# NO /Zp4 ON THIS BLOCK. Every one of the ten was compiled under the port's own
# flags with and without the option and each pair of /FAsc listings came back
# identical outside the TITLE line naming the .obj: 0 diff lines. Block R10a's
# rule for that case is to leave the option off rather than make a claim
# nothing measured.
#
# FIVE OF THE TEN ARE REACHED THROUGH THE TABLES THEMSELVES and five from
# linked ROM code, so all ten have a live referrer after the seat:
#   func_ov002_020f2dd4  <- func_ov002_020f5fb8 (linked)

# ---- gate 2: THE THREE EXTENT-OPEN TABLES ---------------------------------
#
# Lane FWD refused these three because each table is the LAST symbol in its
# overlay's config/arm9/overlays/ovNNN/symbols.txt, so the next-symbol rule
# cannot bound the extent, and "a seat over an unclosed extent can leave a cell
# the matched TU would CALL". delinks.txt bounds it instead: a bss symbol cannot
# run past the end of .bss. Measured for this gate, read-only
# (runs/link100/out/PMFB6/rom_gate2.txt):
#
#   ov089  data_ov089_02132cec   8 filled  .bss ..0x02132d40  slack 0x14 -> 10 cells
#   ov095  data_ov095_02137910   5 filled  .bss ..0x02137940  slack 0x08 ->  6 cells
#   ov092  data_ov092_02132568   9 filled  .bss ..0x021325c0  slack 0x10 -> 11 cells
#
# Every cell of the maximum span is seated: the filled run through the source
# statics the sinit copies from, each checked against the ROM address its body
# was compiled from, and each slack cell past it with an ABORTING face written
# into the mounted bss after asserting those bytes are zero. ov095's single
# slack cell is the exception and its file states it: port/ov095_syms.txt pins
# that mount to 0x28, the filled run, so there is no storage to seat and that
# file is not this lane's.
#
# ROM stride read at each body (`add r3,rX,rY,lsl #3`, pool word == the table):
#   ov089 02132194  pool 02132498 -> 02132cec   STRIDE 8   OK
#   ov095 021364d8  pool 021365d4 -> 02137910   STRIDE 8   OK
#   ov092 02131c44  pool 02131d90 -> 02132568   STRIDE 8   OK
# Emitted stride and arity off each TU's own /FAsc listing under the port's own
# flags: [reg*8] and [reg*8+4] on all three, ARITY ZERO on all three, /Zp4 diff
# 0 lines outside the TITLE on all three. 22 source pairs, every one {code, 0}.
#
