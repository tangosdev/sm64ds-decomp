# This is the SECOND mount of the same overlay, per symbol; --whole emits

#
# delinks.txt sections, base 0x021111a0:
#   .text   0x021111a0..0x02113820   .rodata 0x02113820..0x021138ec
#   .init   0x021138ec..0x02114078   .ctor   0x02114078..0x0211407c
#   .data   0x02114080..0x02114620   .bss    0x02114620..0x021148e0
# Every raw byte below was read out of extracted/overlays/overlay_0034.bin,
# never the dsd export (T4). BASE PROOF: _ZN7WigglerD1Ev (0x021111a0) and
# Wiggler_Spawn (0x021136a4) both read e92d4010 = push {r4,lr};
# _ZN7Wiggler13InitResourcesEv (0x0211323c) and _ZN7Wiggler16CleanupResourcesEv
# (0x02112a5c) both read e92d4ff0 = push {r4-r11,lr}.
#
# ==== THE CAST IS ONE CLASS, BOTH ATTRIBUTION ROUTES ======================
#
#   id   arm9 slot   SpawnInfo   word[0]     factory        +4   x on L26
#   248  0x02090c44  0x02114498  0x021136a4  Wiggler_Spawn  248   1
#
# The record's word[0] lands inside ov034 [0x021111a0, 0x021148e0) and
# relocates to the overlay's own factory; word[1]'s low halfword reads 248, the
# id the arm9 spawn-table slot was reached from. BOTH routes are required --
# the level overlays share the load window at 0x021111a0 and id 248's candidate
# list reads overlays(14,15,16,20,21,22,34). Run over every candidate, exactly
# one overlay satisfies both, and it is ov034.
#
# Level 26 spawns 35 actors and skips 1 on tip 3b4863d9a. That one is this
# class, so this seat takes level 26 to ZERO skipped.
#
# ==== NO IDENTITY SHIFT HERE, AND THE RTTI SAYS SO ========================
#
# Unlike ov032, ov033 and ov035, dsd's names in this overlay are on the right
# class. _ZTV7Wiggler is 0x021144bc, its typeinfo at vtable[-1] is 0x0211445c
# and the name string at 0x02114478 reads "12daHanachan_c" -- Hanachan is the
# ROM's own word for the Wiggler. Wiggler_Spawn installs 0x021144bc, and every
# _ZN7Wiggler* method sits in that table's own slots. Checked, not assumed.
#
# _ZTV7Wiggler  0x021144bc, THIRTY-ONE slots, ends 0x02114538.
#   dsd's next-symbol landing reads 0x7c = 31 slots, which is RIGHT -- the only
#   width in this lane dsd got right, because the state table starts exactly
#   where the vtable ends.
#   Slot 30 is 0x020100dc Actor::OnAimedAtWithEggReturnVec, the last Actor slot,
#   and there is no slot 31: a Wiggler is an Enemy, which is a plain Actor and
#   not a Platform. Six own slots, the usual 0/3/6/9/16/17.
#   The table is EXCLUDED from this mount and hosted as an array
#   hal/actor_classes_ov034.cpp fills.
#
# ==== THE ELEVEN-STATE POINTER-TO-MEMBER TABLE, AND ITS T3 PIN ============
#
# data_ov034_02114538 is an ELEVEN-ENTRY table of TWENTY-byte records:
#   +0x00  the ENTER pmf, an 8-byte mwcc {function, delta} pair
#   +0x08  the TICK pmf,  the same shape
#   +0x10  a pointer to the state's own NAME STRING
# The two pmfs are ZERO in .data and filled by __sinit_ov034_021138ec out of
# twenty-two 8-byte source pairs at 0x02114358..0x02114408. The ROM's own names,
# read out of the +0x10 pointers:
#
#   idx  name          enter        tick
#    0   DEMOWAIT      0x02112484   0x02112348
#    1   DEMOCALL      0x02112330   0x02112284
#    2   MOVE_STOP     0x02112270   0x021120ac
#    3   MOVE_START    0x02112020   0x02111e68
#    4   MOVE          0x02111e4c   0x02111c48
#    5   DAMAGE        0x02111bb0   0x02111a64
#    6   DAMAGETALK    0x02111a0c   0x021119ac
#    7   DEAD          0x02111974   0x02111788
#    8   DAMAGE_STOP   0x02111720   0x021115cc
#    9   DAMAGE_WAIT   0x021115c0   0x02111588
#   10   DAMAGE_START  0x02111520   0x021113d4
#
# Every delta word is zero and all twenty-two handlers have matched src TUs.
# func_ov034_021125b8 writes the index at +0x8c4 and tail-calls the ENTER half;
# func_ov034_02112604 dispatches the TICK half at entry+8. Both dispatch sites
# are host copies (MSVC's PMF representation for an incomplete class is not the
# ROM's {function, delta} pair), and hal/actor_classes_ov034.cpp VERIFIES all
# twenty-two ROM words in the mounted table before rewriting the function words
# with host addresses -- a mount pointing at the wrong bytes aborts instead of
# calling into DS memory.
#
# ==== FOURTEEN T3 WIDTH PINS ==============================================
#
# .rodata -- the two animation-handle ROWS
#   data_ov034_0211389c:0x14  five SharedFilePtr pointers, one per body segment,
#     indexed [i] for i in 0..4 by both _ZN7Wiggler13InitResourcesEv.cpp:92 and
#     _ZN7Wiggler16CleanupResourcesEv.c:26. dsd named 0x021138a8 THREE pointers
#     in, so the landing reads 0xc and segments 3 and 4 would load their
#     animations off whatever the host linker put next. Its five identically
#     shaped siblings at 0x02113838 / 4c / 60 / 74 / 88 all read 0x14 already,
#     which is what pins this one.
#   data_ov034_021138b0:0x14  the same shape one row along; dsd named
#     0x021138bc three pointers in.
#
# .data
#   data_ov034_021143f8:0x8   a PMF source pair; dsd named 0x021143fc one word
#     in, so the landing reads FOUR of eight and the sinit would copy a delta
#     word it does not own.
#   data_ov034_02114450:0xc   the string "DAMAGE_WAIT", twelve bytes with its
#     terminator; dsd named 0x02114458 eight bytes in.
#   Wiggler_SpawnInfo:0x1c    natural 0x24, an OVER-read that would swallow the
#     vtable's own offset-to-top and typeinfo words at 0x021144b4/0x021144b8.
#     A record is 0x1c (the ov032/ov033 measurement), and pinning it leaves
#     those two words to --pack's padding where they belong.
#   data_ov034_02114538:0xdc  THE STATE TABLE, eleven entries of twenty bytes.
#     Natural 0x14 -- dsd named 0x0211454c, 0x02114568, 0x02114598 and
#     0x021145e4 inside it, so the landing reads ONE ENTRY OF ELEVEN. Unpinned,
#     every state past DEMOWAIT would be dispatched out of whatever the host
#     linker put after a twenty-byte array. This is the single most important
#     pin in this overlay. The four interior names are excluded below.
#
# .bss -- eight destructor chain nodes and one SharedFilePtr dsd sized short.
# func_020731dc writes THREE words through its node argument
# (src/func_020731dc.c), so every node is 0xc; a SharedFilePtr is 8.
#   data_ov034_02114628:0x8   natural 0x4  (SharedFilePtr)
#   data_ov034_021147bc:0xc   natural 0x8  (chain node)
#   data_ov034_0211481c:0xc   natural 0x8
#   data_ov034_02114858:0xc   natural 0x8
#   data_ov034_02114870:0xc   natural 0x4
#   data_ov034_02114888:0xc   natural 0x4
#   data_ov034_02114894:0xc   natural 0x4
#   data_ov034_021148ac:0xc   natural 0x8
# The eight interior names dsd invented inside them -- 0x0211462c, 0x021147c4,
# 0x02114824, 0x02114860, 0x02114874, 0x0211488c, 0x02114898, 0x021148b4 -- are
# all marked `ambiguous`, are spelled by NO src TU, and are deliberately not in
# the list: mounting them alongside the pinned parents is a layout --pack
# refuses. The other sixty-two .bss symbols already read 8 or 0xc and are left
# bare, so the diff shows exactly which ones dsd got wrong.
# data_ov034_021148d0 is the LAST symbol in .bss and its landing runs to the
# section end (0x10 for a 0xc node); an over-read costs nothing and is left.
#
# ==== ONE LIVE WRONG-NAME AT THE SHARED WINDOW (T6) =======================
