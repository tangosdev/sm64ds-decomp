# 0x14 + 0x1e + 0x12 + 0x10 + 728 = 0x32c, and 0x0209caa0 + 0x32c = 0x0209cdcc
# is the next symbol in config/arm9/symbols.txt after the four names inside

# cab4 +0x14, cad2 +0x1e, cae4 +0x12, caf4 +0x10, the run ending 0x1332 bytes
# below _dsstate_hi, so all 796 bytes are inside the captured span.
#
# WHAT THIS LANE ADDS is the check, because a grouped-section run is a layout
# and a 796-byte memset onto a reordered layout is silent corruption rather
# than a fault. port_r2a_saveblock_layout() asserts the five offsets on every
# boot and the arm REFUSES rather than memsetting if one has moved.
# The guard compares integer host addresses: the separately declared globals
# do not become a single C++ array merely because the linker places them together.
#
# WHAT THE WRITE DOES ON THIS PATH: nothing observable, and that is stated
# rather than hidden. All five sections are zero-initialised and every host
# writer of the save block in tests/walk_window.cpp is below this seam (the
# pending character at :7743, the opening-seen bit at :8134). The ROM's memset
# writes zeros over zeros. The seat is that the ROM's own body does it, on the
# ROM's own object, at the ROM's own point in its own boot.
