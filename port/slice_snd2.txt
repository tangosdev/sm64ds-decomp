# Lane SND1 took rung R1 (the pool, the status block, the channel-7
# registration) and rungs R8/R9/R10 (the frame). What it left behind is the
# rest of src/func_020133bc.c -- the ROM's Sound::Init -- which
# hal/sdat/consumer.cpp's sd_sound_init_host still transcribes line by line.
# Each rung below deletes one more transcribed line and calls the ROM's own
# body at the ROM's own point, in the ROM's own ORDER. See the header on
# sd_sound_init_host for the order and for which lines are still host lines.
#
# NO SQUARE BRACKETS ANYWHERE IN THIS FILE, and that is not a style note.
# CMake's file(STRINGS) reads an unbalanced open-square-bracket as the start
# of a bracket argument and swallows the REST OF THE FILE into that single
# element, joined with semicolons. Every source line after it then arrives
# glued onto a comment line, the ^# filter in the CMake block drops the
# whole thing, and the slice contributes NOTHING while looking correct. The
# build fails at LINK on the very symbol the slice exists for, which reads
# as a missing source rather than an eaten one. This lane spent a build
# finding that out, on a comment that wrote an address interval the usual
# mathematical way. Write 'base+0x10 up to end' instead.
