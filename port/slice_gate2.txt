# Gate-2 slice: the NitroSystem expanded heap (NNS_FND_expheap.c) -- the allocator LAYER
# only. The Heap class layer above it (CreateRootHeap, SetupRootHeap) reads
# OS arena globals and waits for the OS seam in a later gate.
#
# Chosen second because Andrew's implementation order starts at
# memory/runtime/heaps, and because this is where the LP64 bug class lived:
# an allocator that survives a fill-pattern torture test on the host is the
# strongest layout evidence a port can buy per line of test code.

src/engine/heap/ExpandingHeapAllocator.cpp

# NitroSystem NNS_FND list + heapcommon: NNSi_FndInitHeapHead registers every
# heap in the root heap list, so the list functions ride along. One TU supplies
# both, including NNSi_FndFinalizeHeap.
src/engine/heap/NestedHeapIterator.cpp

# The allocator entry points the ExpandingHeap overrides forward to (the
# seventh, NNSi_FndFinalizeHeap, arrives with the heapcommon TU above). The
# overrides themselves -- including FreeVisitedBlock, which used to be listed
# here as its own shard -- now live in src/engine/heap/Heap.cpp
# (slice_gate3a.txt), which smoke_roots links alongside this slice; each V*
# method is a one-line call into this layer, so a host link that has the
# override and not its target has half of a pair.
