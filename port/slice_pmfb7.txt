# ===========================================================================
# SLICE pmfb7 -- run link100, lane PMFB7, gate 1
# TWELVE OBJECT-FIELD ROWS FROM THE FIVE LARGEST OVERLAY GROUPS
# ===========================================================================
#
# MGWRITER's remaining_object_field_rows.txt left 29 one-per-overlay rows across
# seventeen overlays, each marked "NO universe statement": a pointer to member
# held in a per-instance FIELD can only be seated when the set of source pairs
# that can reach that field is bounded. This gate closes twelve of them.
#
# THE UNIVERSE, per row, from the CLASS and not from a hand-chosen span. The
# code block is the first-to-last address range of every function symbol in
# config/arm9/overlays/ovNNN/symbols.txt whose mangled name names the class --
# the constructor, the destructors and every method -- which is the span one
# translation unit emits. Every `load` relocation in the overlay whose
# destination lands in that block, kept when the word at the FROM address reads
# the destination and the FOLLOWING word is zero, is the whole set of storage
# that can hand this class's field an address in this class:
#
#  row                            ov   class block            pairs run                 words
#  _ZN7Skeeter8BehaviorEv        090  02130f00..02132618   8  021340e0..02134120   8
#  _ZN10CheepCheep8BehaviorEv    090  02133034..02133634   4  021342b8..021342d8   4
#  _ZN8MantaRay8BehaviorEv       090  0213269c..02132fe8   2  021341e4..021341f4   2
#  _ZN5Shark8BehaviorEv          090  0213367c..02133ca0   2  021343a0..021343b0   2
#  _ZN17BowserPuzzlePiece8B..    064  02119330..02119a18   2  0211c2dc..0211c2ec   2
#  _ZN10LavaBubble8BehaviorEv    064  021185c0..02118b08   4  0211be90..0211beb0   4
#  _ZN9WaterRing8BehaviorEv      064  02119a58..0211a1b0   4  0211c3b0..0211c3d0   4
#  _ZN6Snufit8BehaviorEv         065  02115ee0..02116f0c   8  0211cb20..0211cb60   8
#  _ZN5Swoop8BehaviorEv          065  02116f98..02117eac   8  0211cc20..0211cc60   8
#  _ZN12WaterSuction8Behavi..    026  021121fc..02112450   2  02113dd0..02113de0   2
#  _ZN9Submarine8BehaviorEv      026  02111aa0..021121bc   4  02113cec..02113d0c   4
#  _ZN6Bullet8BehaviorEv         002  020feabc..020fefcc   2  0210d5f8..0210d608   2
#
# Twelve for twelve the run is SOLID (stride 8, no gap) and carries as many
# distinct code words as holders, and twelve for twelve it is exactly the run
# the overlay's own seat file already names. The other load relocations into
# each block are the class's seven vtable slots, which are consecutive code
# words rather than {code,0} pairs and the sweep reports as not-pairs.
# (runs/link100/out/PMFB7/recon_all.txt, sweep_gate1.txt)
#
# NO SENTINEL IN THIS GATE, and that is measured, not assumed. Every reference
# INTO any of the twelve runs that comes from outside the class's own code block
# is the class's OWN __sinit copying the records -- the owning symbol of each is
# named in runs/link100/out/PMFB7/sweep_gate1_owners.txt. Nothing compares a
# stored pair by value, so a face per RECORD is exact here and lane FWD's
# one-face-per-code-word rule is not needed and is not claimed.
#
# THE ROM SIDE, read at each body's OWN address out of extracted/overlays/
# (runs/link100/out/PMFB7/rom_gate1_out.txt), e.g. Bullet at 0x020fee44:
#     ldr r1,[r4,#0x350]   the state cell pointer out of the object field
#     ldr r0,[r1,#8]       the CODE word of the pair at cell+8
#     cmp r0,#0            the ROM's own null guard
#     add r3,r1,#8         the pair's address
#     ldr r1,[r3,#4]       the ADJUST word at cell+0xc
#     add r0,r4,r1,asr #1  this + adjust>>1
#     blx r1               a CALL, not a tail jump
# All 48 source pairs of the twelve rows read {code, 0} in the overlay image.
#
# THE EMITTED SIDE, off each TU's own /FAsc listing under the port's own flags
# (runs/link100/out/PMFB7/emit_all21_out.txt): every one of the twelve is
#     mov eax,[cell+8] / test eax,eax / je / mov ecx,[cell+12] /
#     add ecx,this / call eax
# -- +8 and +0xc are the ROM's own offsets, the receiver is in ecx and NOTHING
# is pushed, so ARITY ZERO. Three listings carry an `add esp,4` a few
# instructions earlier and every one is the cleanup of the PRECEDING cdecl call,
# read in the listing rather than counted as an argument.
#
# NO /Zp4 ON THIS BLOCK, measured both ways on all twelve: 0 listing lines
# differ outside the TITLE line naming the .obj. That is what PMFB6's rule
# predicts -- the member sits at offset 8 of its holder struct and 8 mod 8 is 0 --
# and block R10a's treatment for that case is to leave the option off rather
# than make a claim nothing measured.
#
# WHY TWELVE HOST BANNERS WERE WRONG. Each of the twelve host copies refused the
# matched TU because the PMF type is formed over a class that is still
# incomplete, which MSVC widens to the general SIXTEEN-byte representation and
# then reads garbage adjustment fields past an eight-byte record. That was true
# when it was written and is dead now: block R8 turns on /vmg AND /vmm for every
# C++ source in this build, and /vmm chooses the multiple-inheritance worst case,
# which is EIGHT bytes -- the ROM's own {code, adjust} pair. This is PMFB6's
# finding 1 applied to the actor half of the family; the Snowball row in the R10
# block is the same shape already taken and its measurement is in CMakeLists.
#
# WHICH CELLS TAKE A FACE, AND WHICH MUST NOT. Each class's records are copied
# in PAIRS into a 16-byte bss cell: slot 0 the ENTER half, slot 1 the per-frame
# half. These twelve Behaviors dispatch slot 1 and they CALL it, so slot 1
# becomes a zero-argument __fastcall face. Slot 0 is dispatched by the class's
# state-change helper -- func_ov090_02131e00, _021332e8, _021338b4, _02132ac4,
# func_ov065_0211691c, _02117944, func_ov002_020fed2c -- and every one of those
# compiles to `jmp edx`, a tail jump that reuses the caller's own cdecl frame and
# leaves the receiver at [esp+4], so a plain cdecl body is right there and a face
# would be wrong. Slot 0 is not touched. The split is read out of each class's
# own __sinit, and every seat file's existing enter/tick labels agree with it.
#
# NINE OF THE TWELVE NEED A FORWARDER (their matched TU defines
# ?Behavior@<Class>@@QAEHXZ, a real C++ member, while the actor class table
# calls the flat name): they join lane FWD's in port/hal/fwd_forwarders.cpp.
# MantaRay, Shark and Skeeter define the flat extern "C" name themselves.
# ===========================================================================

# The block is derived from the class the same way gate 1's twelve are: the
# first-to-last address range of every function symbol in that overlay's
# symbols.txt whose mangled name names the class. Nine for nine the sweep gives
# ONE SOLID run of {code,0} pairs, stride 8, no gap, with as many distinct code
# words as holders, and nine for nine every reference into the run from outside
# the block is the class's OWN __sinit -- the owning symbol of each is named in
# runs/link100/out/PMFB7/sweep_gate2_owners.txt. No by-value sentinel, so a face
# per record is exact.
#
# Nine for nine the emitted dispatch is `mov eax,[cell+8] / test eax,eax / je /
# mov ecx,[cell+12] / add ecx,this / call eax` -- ARITY ZERO, receiver in ecx --
# and /Zp4 changes 0 listing lines outside the TITLE. Chuckya's second indirect
# site is an ordinary virtual call through the model's vptr+0xc, not a pointer to
# member, and it is untouched.
#
# Only the PER-FRAME half of each cell takes a face. The enter half is reached by
# the class's state-change helper, which compiles as a one-call forwarder ending
# in `jmp`, so the caller's own cdecl frame is reused and a plain cdecl body is
# right there. The split is read out of each class's own __sinit
# (runs/link100/out/PMFB7/slots_gate2.txt); where a seat file already carried
# enter/tick labels -- ov091's FWOOSH rows, ov094's cells, ov066's cells -- they
# agree with it row for row.
#
# HootTheOwl IS NOT TAKEN, and what stops it is not the sweep. Its universe
# closes like the other eight -- ten pairs, five cells, no sentinel -- but the
# matched TU carries a WRONG-OVERLAY CROSSING: the ROM's own Behavior at
# 0x02136478 calls 0x021357a4 at 0x021365fc, ov094 and ov096 share the base
# 0x02135700, and src/_ZN10HootTheOwl8BehaviorEv.cpp spells that call
# func_ov096_021357a4 -- an EIGHT-byte ov096 stub -- where the ROM reaches
# ov094's own 0x110-byte body. The host copy this row would have retired
# spelled it func_ov094_021357a4 and was right. Seating the row therefore
# RAISES the linkage count and makes the port call the wrong body, and it is
# visible in the count: func_ov094_021357a4 loses its last referrer and
# /OPT:REF strips it, and src/func_ov002_020df840.c goes with it because
# 021357a4 was ITS last referrer. Two matched TUs leave the binary to gain one.
# The unblock is decomp-side -- the crossing has to be corrected in
# src/_ZN10HootTheOwl8BehaviorEv.cpp -- and it is not this lane's file.
# The other TWENTY rows of this slice were checked the same way, EXTRN list
# against the row's own overlay, and none carries a foreign-overlay call.
