# aritycheck_plainfunc_baseline.txt
#
# The frozen set of PLAIN-NAME arity drops: a PROTOTYPED declaration of an
# address-named C symbol (func_XXXXXXXX / func_ovNNN_XXXXXXXX) that takes
# fewer parameters than the definition, in a TU that actually CALLS the
# symbol, where every parameter on both sides provably occupies one machine
# word. Under those three conditions -- and only under them -- "fewer
# parameters" literally means the call pushes fewer words than the callee
# reads, on ARM AAPCS and x86 __cdecl alike. On ARM the missing word often
# rides a register that happens to still be live, which is why the byte gate
# stays green over these; on the host the callee reads a stack slot nobody
# wrote.
#
# THIS IS THE SHAPE THAT SHIPPED A SOFTLOCK, found by run mg8 lane SBN on
# 2026-08-22: src/func_ov006_020d8cc4.cpp declared
#
#     extern "C" int func_ov006_020d836c(void);
#
# and called it with nothing, while the definition takes the per-bomb
# receiver. 020d836c is the per-bomb tick of scene 370's Sort or 'Splode,
# and during the bin-full sweep its caller is the only thing driving it, so
# the game hung forever the first time a sorting bin filled. Fixed in
# ba2224f88. That row is ABSENT from this file, because it is fixed -- the
# same proof-of-usefulness the receiver baseline carries for #1539/#1543.
# The gate that existed at the time was scoped to _ZN member names and could
# not see a plain name; this file is the closing of that scoping.
#
# WHAT A ROW IS. `<symbol>|<declaring file>`, never a line number, exactly as
# in aritycheck_receiver_baseline.txt: a key that carries a line moves every
# time somebody adds a comment above it. For a declaration in a HEADER the
# declaring file is the header itself, and the call that qualifies it lives
# in whichever TU includes the header.
#
# THESE ROWS ARE DEBT AND NOT CLEARANCE. Nobody has adjudicated them one by
# one. Each one is a call site that pushes fewer words than its callee's
# definition reads, and each is invisible to the byte gate for the same
# register-happens-to-be-live reason the Sort or 'Splode row was. Anyone who
# works through a row and finds it real should fix it the way ba2224f88 did
# (declare the full signature, pass the value the ROM leaves in the
# register, re-verify the byte match) and delete the line; anyone who finds
# the checker wrong about a row should say so beside it. The list may only
# shrink.
#
# TWO ROWS WORTH NAMING UP FRONT:
#   func_ov007_020ae558|src/func_ov007_020add3c.c
#       The Class A seam of port/tools/tailjump_guard.py: the caller is
#       form=call, not a jump, so no RIDE exclusion applies and the row is

#       guard existed; it stays here rather than being re-discovered.
#   func_0203dabc|include/decl_common.h   -- FIXED AND REMOVED, run mg15 MP1.
#       It was a header prototype: decl_common.h spelled it (void), both
#       definitions take the comms slot index, and src/func_ov007_020cc2cc.c
#       called it with nothing through the include. mg15 lane MP1 gave the
#       header the parameter and the caller the explicit argument

#       still MATCH at 2004/b56 with strict relocs. Its sibling row
#       func_0203dae4|include/decl_common.h went with it. Kept here as the
#       worked example of a header row that could be CLOSED rather than
#       ridden, since this file may only shrink.
