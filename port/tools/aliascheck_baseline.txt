# aliascheck_baseline.txt
#
# The frozen set of /alternatename directives whose two sides DISAGREE ABOUT
# WHERE THE RECEIVER LIVES. MSVC __thiscall takes it in ECX; every other
# spelling in this tree takes it as an ordinary first stack argument, or has no
# receiver at all. A directive that crosses that line delivers the object
# somewhere the body does not read.
#
# THIS FILE IS A RATCHET AND IT MAY ONLY SHRINK. A crossing that is not listed
# here fails port/tools/aliascheck.py. Landing a NEW one is the thing this
# exists to prevent; retiring an old one is the thing it exists to make
# visible.
#
# EVERY ROW CARRIES AN ADJUDICATION, AND AN UNADJUDICATED ROW IS NOT ALLOWED.
# The tag after the # is one of:
#
#   OPEN    a LIVE DEFECT. A caller demonstrably passes the receiver the way
#           the other side does not read it. These are not cleared, they are
#           COUNTED, and aliascheck reports them separately from regressions
#           so the count cannot be mistaken for a green.
#   INERT   the crossing is real but cannot misbehave, for a stated and
#           checked reason -- the body never reads the receiver, the
#           dispatcher puts it in ECX anyway, or the directive is defeated by
#           a defined LHS so it never fires at all.
#
# HOW THE 2026-08-17 ADJUDICATION WAS DONE (run link60, lane AB1). For each
# crossing: find every reference to the crossing name in src/, port/hal/ and
# port/unmatched/; decide per site whether it CALLS the name (and with what)
# or only TAKES ITS ADDRESS; read the body it resolves to and see whether that
# body reads the receiver at all. A crossing is INERT only where that walk
# reaches a reason, never where it merely fails to reach a caller.
#
# ---------------------------------------------------------------------------
