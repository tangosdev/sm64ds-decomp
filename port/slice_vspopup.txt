# Lane VSARENA2 read seven of the owner's own live VS playlogs. Every one of

#
#     [spawn-declined] actor 0x14a not registered

# pops when a player takes a star -- and 0x159 is WingFeather, the wing-cap
# feather. Neither id appears in ANY level's object table, on any of the 44
# levels whose overlay decodes: both are spawned at run time, which is exactly
# why no boot census ever asked for them and no earlier gate noticed they were
# missing. In a star battle the score number simply never appeared.
