# The two ROM pointer tables the sweep found -- their CALLEES.

# port/tools/ptr_audit.py intersects romdata.py's NAMED list with
# config/arm9/relocs.txt and reports every named symbol whose bytes
# contain a relocated word. Two of its answers are tables that matched
# code indexes and CALLS. Both are hosted with real host function
# pointers in port/hal/ptr_tables.cpp, which is only possible if the
# callees exist as host code -- that is this list.

# Nothing here is new decomp. Every file is matched src that had simply
# never been named by any slice, because the only thing naming it was a
# table of bytes.
