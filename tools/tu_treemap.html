Select a TU to inspect its source and reconstruction evidence.

Area measures code bytes, not source length or data sections. Colors measure TU enrollment, independently of function matching. Membership comes from config/tu_manifest.d/ and complete source ownership. Production enrollment requires every declared function to belong to the existing promoted source in complete delinks ranges. Additional functions compiled from that same source join its TU when ownership is unambiguous. Unassigned is one aggregate per module, not an inferred TU. Candidate boundaries without manifests are not asserted as recovered files.
