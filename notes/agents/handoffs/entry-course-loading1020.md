## Recovered behavior and interfaces

The six typed transition helpers and their fifteen callers remain in their current production owners. `StepSet` is three eight-byte member pointers; the pending set remains at 0x6c. The helpers preserve immediate entry, delayed transitions, outgoing render callbacks and the fade ramp.

Course selection uses four course icons and a fifth title icon. Network selection, local touch handling, readiness, confirmation and cancellation are retained. The selected byte indexes the signed level table used to start the match; the inferred names describe course selection rather than claiming interactive character selection. `ArePlayersReady()` retains the implicit scene argument at all four callers, including the caller within the consolidated upper TU. The ARM9 selection getter now explicitly takes no arguments.

The next step set is `EntryMatchLoadingSteps`, supported by the initializer's copies of the enter and update member pointers. `EnterMatchLoading` initializes the resource phase, 240-tick countdown and signal latch. `UpdateMatchLoading` starts one resource job, polls completion, waits for an observed peer signal to clear, and requires the countdown to expire before `StartMatch`. The received signal tested by `func_0203d8fc` is bit 0x2000; the local signal manipulated by the publish/clear helpers is bit 0x4000. They are distinct sides of the protocol.

`LoadCourseResources(int course)` is a static member: the scheduler passes the selected course in r0, with no scene argument. It temporarily selects the loading heap, loads archive 7, unloads unselected archives 2 through 5, loads the selected archive, restores the previous heap, then loads the selected level resources. `StartMatch()` is an instance method because its sole caller supplies the scene; it starts the signed level-table entry and stops the loaded music. Its old no-argument free-function definition disagreed with that caller. Clearing the behavior uses native `mBehaviorStep = 0`; the compiler supplies the runtime null-member-pointer constant, removing the old local storage view. The player-count global used by loading is declared as the byte scalar its other callers use, retiring the prior array disagreement.

`mSawLoadSignal` is an inferred s32 view of the workspace at 0x268, reused by other states. `MatchLoadPhase` names the values stored in the existing byte-sized phase field; it does not enlarge that field. The class remains 0x288 bytes. Callback and global names are inferred, not recovered original spellings.
